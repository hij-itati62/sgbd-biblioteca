**Pregunta:**
¿Cómo estructuro un sistema de biblioteca en Python usando POO?

**Respuesta (resumen):**
Se sugirió dividir el sistema en clases como Libro, Usuario y Catálogo, aplicando herencia y separación por módulos.

**Uso:**
Se creó la carpeta modelos y las clases base del sistema.
